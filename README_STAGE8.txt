مرحله 8 — ورود با موبایل + رمز عبور

تغییرات:
- ورود همه کاربران: شماره موبایل + رمز عبور
- ایمیل اختیاری و قابل ویرایش در پروفایل کسب‌وکار
- OTP ایمیلی از مسیر فعال حذف شده (مدل/سرویس برای آینده باقی مانده)
- ثبت‌نام اولیه صاحب کسب‌وکار: موبایل + رمز + ایمیل اختیاری
- رزرو مشتری مهمان: نام + موبایل + رمز + ایمیل اختیاری در آخر رزرو
  * اگر شماره قبلاً وجود داشته باشد، رمز بررسی و همان حساب وارد می‌شود
  * اگر شماره جدید باشد، حساب مشتری همان‌جا ساخته و نوبت ثبت می‌شود
- حداقل رمز: 6 کاراکتر
- Seed جدید: رمز همه حساب‌های تستی 123456

پیشنهاد برای دیتابیس تستی:
python manage.py migrate
python manage.py seed --clear
python manage.py runserver

اگر دیتابیس را کامل پاک کرده‌ای:
python manage.py makemigrations
python manage.py migrate
python manage.py seed
python manage.py runserver
