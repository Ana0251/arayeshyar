مرحله 4B — احراز هویت نهایی ایمیلی + ثبت‌نام کسب‌وکار + Seed جدید
=================================================================

تغییرات اصلی
-------------
1) email شناسه اصلی User و USERNAME_FIELD است.
2) ورود پیامکی قدیمی از URL/UI حذف شده است.
3) phone اختیاری است و فقط برای تماس، SMS و جست‌وجو نگه داشته می‌شود.
4) OTP فقط ایمیلی است و کد به‌صورت hash در DB ذخیره می‌شود.
5) نشست ورود روی دستگاه تا 30 روز نگه داشته می‌شود.
6) کلیک روی ثبت‌نام کسب‌وکار، کاربر مهمان را اول برای تأیید ایمیل می‌برد و سپس به روند ثبت‌نام برمی‌گرداند.
7) در مرحله اطلاعات کسب‌وکار، شماره موبایل مدیر گرفته و روی User ذخیره می‌شود.
8) seed.py با ایمیل‌های تستی جدید هماهنگ شده است.

نصب
----
فایل‌ها را با همان مسیر روی پروژه جایگزین کنید، سپس:

    python manage.py migrate
    python manage.py check
    python manage.py seed --clear
    python manage.py runserver

در محیط توسعه، Django از console email backend استفاده می‌کند؛ کد OTP داخل ترمینال چاپ می‌شود.

تست پیشنهادی
------------
A) مهمان -> ثبت‌نام کسب‌وکار
   باید به فرم ایمیل برود، OTP را تأیید کند و به /register/ برگردد.

B) مراحل ثبت‌نام را کامل کنید.
   در مرحله اطلاعات، ایمیل فقط خواندنی و موبایل مدیر قابل ورود است.

C) پس از ثبت نهایی:
   User.role باید business_owner باشد و phone روی User ذخیره شده باشد.

D) /auth/login/ فقط ورود ایمیلی را نشان دهد.
   مسیر قدیمی /auth/login/phone/ دیگر وجود ندارد.

نکته
----
Migration 0003 برای دیتابیس تستی قبلی نیز OTPهای دوره گذار را پاک می‌کند و Userهای بدون ایمیل را موقتاً با ایمیل legacy پر می‌کند تا migration fail نشود. اگر دیتابیس را از صفر بسازید نیز 0001 -> 0002 -> 0003 بدون نیاز به داده قبلی اجرا می‌شود.
